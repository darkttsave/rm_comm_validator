## 一、变更摘要

### 1.1 新增功能

✅ **Web UI 界面**
- Flask 后端 + 原生 HTML/CSS/JavaScript
- 实时数据展示
- 无需 CAN 硬件即可在浏览器中查看

✅ **Demo 模式**
- 模拟 CAN 消息生成
- 复用现有 Encoder/Decoder/Validator 管道
- 支持错误注入功能

✅ **Replay 模式**
- 从 JSONL 日志回放
- 不修改原始文件
- 支持进度跟踪

### 1.2 架构增强

```
V1.0 架构                    V1.1 架构
──────────────              ──────────────────────
Protocol                     Protocol
   ↓                            ↓
Decoder                      Decoder
   ↓                            ↓
Validator                    Validator
   ↓                            ↓
   ↓                         Common State
   ↓                        ↙           ↘
Terminal Dashboard     Terminal      Web UI
   ↓                   Dashboard        ↓
Recorder                   ↓         Recorder
                        Recorder
                           ↑
                    ┌──────┴──────┐
                    ↓      ↓      ↓
                 Demo  Replay  Live
                Source Source  (SocketCAN)
```

**关键原则**: Web UI 和 Terminal 共享同一套 Decoder/Validator，没有重复实现协议解析逻辑。

## 五、Demo 模式详解

### 5.1 数据生成策略

#### Quaternion (0x01)
- 模拟绕 Z 轴旋转
- 保持四元数范数 ≈ 1.0
- 添加小噪声模拟真实传感器
- 频率: ~100 Hz

#### Robot State (0x110)
- bullet_speed: 26~30 正弦波动
- mode: 循环 5 种模式
- shoot_mode: 随机选择
- ft_angle: 正弦变化
- 频率: ~20 Hz

### 5.2 错误注入机制

开启后随机产生 (~5% 概率):
- **非法枚举**: mode = 7 (不在 0~4 范围)
- **非法四元数**: 破坏归一化 (norm ≠ 1)
- **未知 CAN ID**: 0x123 (2% 概率)

### 5.3 管道验证

```
Golden/Simulated Fields
         ↓
      Encoder  ← 复用 V1 编码器
         ↓
    Raw CAN Frame
         ↓
      Decoder  ← 复用 V1 解码器
         ↓
    Validator  ← 复用 V1 验证器
         ↓
      Web UI
```

**重要**: Demo 不是直接生成 `fields = {...}` 显示，而是走完整的 encode → decode → validate 流程，确保展示的是真实验证器的结果。

## 九、架构增量说明

### 9.1 数据源抽象

新增统一数据源概念：

```python
# 三种数据源产生相同的内部结构
DemoSource      ──┐
ReplaySource    ──┼──→ (can_id, raw_data, timestamp)
SocketCANSource ──┘              ↓
                          handle_frame()
                                 ↓
                              Decoder
                                 ↓
                             Validator
                                 ↓
                          ┌──────┴──────┐
                          ↓             ↓
                      Terminal        Web UI
```

### 9.2 共享状态管理

Web 应用维护全局状态 `AppState`:
- 统计信息 (total/valid/invalid/unknown)
- 最新消息 (按类型分组)
- 近期事件 (最多 20 条)
- 帧率跟踪 (按 CAN ID)

### 9.3 API 设计

#### 状态类 API
- `GET /api/status` - 整体状态和统计
- `GET /api/messages` - 所有最新消息
- `GET /api/rates` - 帧率信息
- `GET /api/events` - 近期事件

#### 控制类 API
- `POST /api/start_demo` - 启动 Demo
- `POST /api/start_replay` - 启动 Replay
- `POST /api/stop` - 停止
- `POST /api/toggle_error_injection` - 错误注入开关

#### 辅助类 API
- `GET /api/list_logs` - 列出可用日志
